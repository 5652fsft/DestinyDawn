# Destiny Dawn — 命运破晓

**回合制六边形战棋卡牌游戏 | Godot 4.7 | 开发者：5652**

---

## 简介

《命运破晓》是一款 3v3 回合制策略游戏。每局从多名角色中挑选 3 人组队，在六边形地图上
与对手展开对战。移动、攻击、释放技能、使用卡牌——活用每回合的有限行动来赢得胜利。

---

## 🎮 快速开始

### 安装和运行
1. **环境要求**：Godot 4.7.1 或更高版本
2. **克隆项目**：`git clone [项目地址]`
3. **打开项目**：使用 Godot 编辑器打开项目文件夹
4. **运行游戏**：点击"运行当前场景"或按 F5

### 基本操作
- **鼠标左键**：选择角色、使用技能、拖拽卡牌
- **鼠标右键**：拖拽地图视角
- **滚轮**：缩放地图
- **F键**：收起/展开手牌
- **ESC键**：打开投降菜单

### 游戏流程
1. **编队管理**：从多名角色中选择 3 人组成队伍
2. **卡组构筑**：从数十张卡牌中选择 8 张构成牌库
3. **选择模式**：LAN联机、单机人机
4. **战斗**：移动→攻击/技能→结束回合（卡牌由玩家独立释放，不消耗角色行动次数）

## 基础规则

### 回合流程

每回合只有**一个阶段**，双方轮流行动。

```
回合开始（抽牌 + 恢复能量）
  ├── 先手回合：先手方行动（移动 + 攻击/技能），玩家可随时释放卡牌
  └── 后手回合：后手方行动（移动 + 攻击/技能），玩家可随时释放卡牌
```

> 先手顺序每回合随机决定。**必须点击「结束回合」按钮手动推进。**

### 每个角色的行动

- **移动**：每回合 1 次，消耗移动力在六边形格子上行走
- **普通攻击**：对攻击范围内的敌人造成伤害
- **释放技能**：每个角色有独特的主动技能，有冷却回合
- **使用卡牌**：拖拽到目标释放，由玩家独立释放，不消耗角色行动次数

> 芝士仓鼠拥有击杀再动奖励（「钢铁直架」天赋），其他角色没有多动奖励。

## 🌐 联机系统

| 场景 | 方式 |
|------|------|
| **同一局域网** | 房间码自动显示本地 IP |
| **VPN 虚拟网络** | Radmin / ZeroTier，自动检测 |
| **本机双开** | 127.0.0.1 |

如果连不上：装 Radmin VPN / ZeroTier → 主机路由器转发 UDP 端口 → 检查防火墙。
