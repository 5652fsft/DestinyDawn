# Destiny Dawn — 命运破晓

**回合制六边形战棋卡牌游戏 | Godot 4.7**

---

## 简介

《命运破晓》是一款 3v3 回合制策略游戏。每局从 6 名角色中挑选 3 人组队，在六边形地图上
与对手展开对战。移动、攻击、释放技能、使用卡牌——活用每回合的有限行动来赢得胜利。

## 基础规则

### 回合流程

每回合只有一个阶段，双方轮流行动，每个角色可移动一次 + 攻击/技能/卡牌一次：

```
回合开始（抽牌 + 恢复能量）
  ├── 先手回合：先手方所有角色行动（移动 + 攻击/技能/卡牌）
  └── 后手回合：后手方所有角色行动（移动 + 攻击/技能/卡牌）
```

> 先手顺序每回合随机决定。**必须点击「结束回合」按钮手动推进到对方回合。**

### 每个角色的行动

- **移动**：每回合 1 次，消耗移动力在六边形格子上行走
- **攻击/技能/卡牌**：每回合 1 次行动，可选择：
  - **普通攻击**：对攻击范围内的敌人造成伤害
  - **释放技能**：每个角色有独特的主动技能（有冷却回合）
  - **使用卡牌**：从手牌中选择卡牌拖拽到目标上释放
- **芝士仓鼠**：天赋「钢铁直架」在消灭敌人后获得 1 次额外行动和 1 层嗜血效果；技能「动作如潮」也能获得额外行动。其他角色没有多动奖励。

## 操作指南

### 鼠标操作

| 操作 | 效果 |
|---|---|
| **左键点击己方角色** | 选中角色，属性面板显示「移动」「普通攻击」按钮 |
| **左键点击「移动」按钮** | 显示移动范围，点击格子移动角色 |
| **左键点击「普通攻击」按钮** | 显示攻击范围，点击敌人攻击 |
| **左键点击地面（非移动模式）** | 取消选中 |
| **右键拖拽** | 拖拽地图视野 |
| **滚轮** | 缩放地图 |
| **左键拖拽卡牌到目标上** | 使用卡牌 |
| **点击「结束回合」按钮** | 手动结束当前回合 |
| **F 键** | 收起/展开手牌（遮挡视线时使用） |

### 界面说明

| 界面元素 | 说明 |
|---|---|
| **左侧角色信息面板** | 显示选中角色的属性、效果（可滚动） |
| **左侧天赋面板** | 显示选中角色的天赋技能详情 |
| **左侧技能面板** | 显示主动技能，点击「使用技能」释放 |
| **底部手牌栏** | 当前手牌，拖拽到目标上使用 |
| **右侧居中回合指示器** | 显示当前回合和「结束回合」按钮 |
| **右下/右上能量显示** | 己方能量（右下）与对方能量（右上），每回合 +2，上限 10 |
| **上方 Toast 提示** | 游戏内即时消息提醒 |

### 编队管理界面

从 6 名角色中选择 3 人组成出战队伍：

1. 左侧是角色列表，点击角色卡牌可翻转查看详细属性
2. 点击角色卡牌上的 **选择** 按钮将其加入右侧队伍槽位
3. 右侧 3 个槽位分别对应出战位置 1/2/3
4. 点击已选角色的 **移除** 按钮可取消选择
5. 编队完成后点击 **保存** 返回主菜单

### 卡组构筑界面

从 30 张卡牌中选择 8 张构成牌库：

1. 上方是卡牌池，显示卡牌名称、费用（左下圆圈数字）、类型和效果描述
2. 点击卡牌池中的卡牌将其加入下方牌组槽位
3. 下方 8 个槽位显示已选卡牌
4. 点击已选卡牌的 **移除** 按钮取消选择
5. 点击 **重置** 清空并重新选择
6. 卡组完成后点击 **保存** 返回主菜单

## 卡牌系统

### 费用

使用卡牌需要消耗能量。每回合自动恢复 2 点能量，能量上限 10 点。

### 卡牌类型

| 类型 | 说明 |
|---|---|
| **攻击** | 对敌人造成伤害 |
| **治疗** | 恢复友方生命值 |
| **护盾** | 提供一次性伤害吸收 |
| **强化 (Buff)** | 提升友方属性 |
| **弱化 (Debuff)** | 降低敌方属性 |
| **位移** | 改变角色位置 |
| **战术** | 抽牌、净化、嘲讽等功能卡 |

### 部分关键卡牌

| 卡牌 | 费用 | 效果 |
|---|---|---|
| 火球术 | 2 | 20 伤害 + 灼烧 2 回合 |
| 瞄准射击 | 2 | 28 伤害（最高单体爆发） |
| 治愈之光 | 2 | 恢复 20 生命 |
| 护盾屏障 | 2 | 提供 16 护盾 |
| 铁壁防御 | 1 | 伤害减免 +8（2 回合） |
| 力量强化 | 1 | 攻击力 +8（2 回合） |
| 谋略 | 1 | 抽 1 张牌 |
| 能量过载 | 0 | +2 能量，自伤 5 |
| 暗影步 | 2 | 传送至目标旁 + 12 伤害 |
| 闪电链 | 3 | 20 伤害 + 链式跳跃 |
| 惩戒 | 1 | 伤害 = 6 × 目标 buff 数 |

> 卡牌效果请参考游戏内卡牌详情。强度与费用正相关：高费卡牌提供更高的效果价值。

## 胜负条件

- **全灭敌方所有角色**即为胜利
- 己方全部角色阵亡即为失败
- 结算界面会显示双方的伤害、治疗、卡牌使用和击杀统计

## 技术特色

### 六边形网格系统
- 基于TileMapLayer的高效六边形渲染
- BFS算法计算可达区域
- 不同地形消耗不同移动力

### 智能AI系统
- 基于评分的行动决策
- 考虑移动、攻击、技能、卡牌的综合评估
- 适应不同游戏难度的AI策略

### 网络同步系统
- ENet P2P低延迟通信
- 实时同步所有角色状态
- 合理的同步策略优化网络流量

### 动态背景系统
- 单例背景管理器
- 场景切换时背景无缝继续播放
- 战斗时自动隐藏/恢复背景

---

## 提示

1. **能量管理**：0 费卡牌「能量过载」可以快速获得能量，但会自伤
2. **芝士仓鼠**：全游戏唯一拥有击杀再动奖励的角色，血量极低但伤害最高。保护己方仓鼠或优先击杀敌方仓鼠是胜负关键
3. **地形利用**：不同地形消耗不同移动力，合理规划路线
4. **编队搭配**：建议搭配坦克 + 输出 + 辅助的组合，不要全选同一类型
5. **背景设置**：在设置界面可以选择喜欢的动态背景，进入战斗时会自动隐藏
