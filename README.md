# Destiny Dawn — 命运破晓

**回合制六边形战棋卡牌游戏 | Godot 4.7 | 开发者：5652**

---

## 简介

《命运破晓》是一款 3v3 回合制策略游戏。每局从多名角色中挑选 3 人组队，在六边形地图上
与对手展开对战。移动、攻击、释放技能、使用卡牌——活用每回合的有限行动来赢得胜利。

---

## 快速开始
### 基本操作
- **鼠标左键**：选择角色、使用技能、拖拽卡牌
- **鼠标右键**：拖拽地图视角
- **滚轮**：缩放地图
- **F键**：收起/展开手牌
- **ESC键**：打开投降菜单

### 安卓端操作（Android 版）
- **单指点击/拖拽**：等同鼠标左键（选角色、拖牌、移动/攻击）
- **双指捏合**：缩放地图
- **双指拖动**：平移视角（替代鼠标右键）
- **「手牌」按钮**：收起/展开手牌（替代 F 键）
- **「菜单」按钮**：打开投降菜单（替代 ESC 键）
- 安卓支持动态背景视频（与 Windows 相同选项，设置页可选）

### 游戏流程
1. **编队管理**：从多名角色中选择 3 人组成队伍
2. **卡组构筑**：从多张卡牌中选择 8 张构成牌库
3. **选择模式**：单人游戏、联机游戏
4. **战斗**：移动、行动（攻击/技能），卡牌由玩家独立释放，不消耗角色行动次数 → 结束回合

## 基础规则

### 回合流程

每回合只有**一个阶段**，双方轮流行动。

```
回合开始（抽牌 + 恢复能量）
  ├── 先手回合：先手方行动（移动 + 攻击/技能），玩家可随时释放卡牌
  └── 后手回合：后手方行动（移动 + 攻击/技能），玩家可随时释放卡牌
```

> 先手顺序每回合随机决定，点击「结束回合」按钮手动推进回合

### 每个角色的操作

- **移动**：一般为每回合 1 次，在六边形格子上行走，不超过移动范围
- **普通攻击**：对攻击范围内的敌人造成伤害
- **释放技能**：每个角色有独特的主动技能，有冷却回合
- **使用卡牌**：拖拽到目标释放，由玩家独立释放，不消耗角色行动次数

> 提示：部分角色拥有额外回合机制

## 联机系统

| 场景 | 方式 |
|------|------|
| **同一局域网** | 房间码自动显示本地 IP |
| **跨网联机（推荐）** | EasyTier（免费开源组网），虚拟 IP 自动识别 |
| **跨网联机（备选）** | 蒲公英（贝锐，免费 3 设备），虚拟 IP 自动识别 |

### 跨网联机步骤（以 EasyTier 为例）

1. 电脑装 EasyTier Windows 版（GUI），安卓手机装对应 APK（GitHub Releases 或国内镜像）
2. 双方填写**相同的网络名与密钥**，加入同一虚拟网络（虚拟 IP 形如 `10.144.144.x`）
3. 主机创建房间，房间码自动显示 VPN 虚拟 IP（形如 `10.144.144.x:1145`）
4. 另一侧「联机 → 加入」输入该房间码即可对局

> **蒲公英备选**：电脑与手机各装蒲公英客户端，登录同一贝锐账号组网（免费支持 3 台设备，不限速），虚拟 IP 形如 `172.47.x.x`，游戏同样自动识别。
>
> **注意**：安卓端受移动 NAT 限制，UPnP 通常失败；跨网对局请使用上述组网方式。若连不上，再检查双方防火墙放行 UDP 1145 端口。
