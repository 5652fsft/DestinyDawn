# Destiny Dawn — 命运破晓

**回合制六边形战棋卡牌游戏 | Godot 4.7 | 开发者：5652**

---

## 简介

《命运破晓》是一款 3v3 回合制策略游戏。每局从 9 名角色中挑选 3 人组队，在六边形地图上
与对手展开对战。移动、攻击、释放技能、使用卡牌——活用每回合的有限行动来赢得胜利。

---

## 🎮 快速开始

### 安装和运行
1. **环境要求**：Godot 4.7.1 或更高版本
2. **克隆项目**：`git clone [项目地址]`
3. **打开项目**：使用 Godot 编辑器打开项目文件夹
4. **运行游戏**：点击"运行当前场景"或按 F5

### 基本操作
- **鼠标左键**：选择角色、使用技能、拖拽卡牌
- **鼠标右键**：拖拽地图视角
- **滚轮**：缩放地图
- **F键**：收起/展开手牌
- **ESC键**：打开投降菜单

### 游戏流程
1. **编队管理**：从6名角色中选择3人组成队伍
2. **卡组构筑**：从35张卡牌中选择8张构成牌库
3. **选择模式**：LAN联机、单机人机或创建房间
4. **战斗**：移动→攻击/技能→结束回合（卡牌由玩家独立释放）

## 基础规则

### 回合流程

每回合只有一个阶段，双方轮流行动，每个角色可移动一次 + 攻击/技能一次，卡牌由玩家独立释放（不消耗角色行动次数）：

```
回合开始（抽牌 + 恢复能量）
  ├── 先手回合：先手方所有角色行动（移动 + 攻击/技能），玩家可随时释放卡牌
  └── 后手回合：后手方所有角色行动（移动 + 攻击/技能），玩家可随时释放卡牌
```

> 先手顺序每回合随机决定。**必须点击「结束回合」按钮手动推进到对方回合。**

### 每个角色的行动

- **移动**：每回合 1 次，消耗移动力在六边形格子上行走
- **攻击/技能/卡牌**：
  - **普通攻击**：对攻击范围内的敌人造成伤害（消耗角色行动）
  - **释放技能**：每个角色有独特的主动技能，有冷却回合（消耗角色行动）
  - **使用卡牌**：从手牌中拖拽卡牌到目标释放（由玩家独立释放，不消耗角色行动次数，消耗能量）
- **芝士仓鼠**：天赋「钢铁直架」在消灭敌人后获得 1 次额外行动和 1 层嗜血效果；技能「动作如潮」也能获得额外行动。其他角色没有多动奖励。

### 编队管理界面

从 9 名角色中选择 3 人组成出战队伍：

1. 左侧是角色列表，点击角色卡牌可翻转查看详细属性
2. 点击角色卡牌上的 **选择** 按钮将其加入右侧队伍槽位
3. 右侧 3 个槽位分别对应出战位置 1/2/3
4. 点击已选角色的 **移除** 按钮可取消选择
5. 编队完成后点击 **保存** 返回主菜单

### 卡组构筑界面

从 35 张卡牌中选择 8 张构成牌库（卡牌池随版本更新持续扩充）：

1. 上方是卡牌池，显示卡牌名称、费用（左下圆圈数字）、类型和效果描述
2. 点击卡牌池中的卡牌将其加入下方牌组槽位
3. 下方 8 个槽位显示已选卡牌
4. 点击已选卡牌的 **移除** 按钮取消选择
5. 点击 **重置** 清空并重新选择
6. 卡组完成后点击 **保存** 返回主菜单

- 结算界面会显示双方的伤害、治疗、卡牌使用和击杀统计

## 提示

1. **能量管理**：0 费卡牌「能量过载」可以快速获得能量，但会自伤
2. **芝士仓鼠**：全游戏拥有击杀再动奖励的角色，血量极低但伤害最高。保护己方仓鼠或优先击杀敌方仓鼠是胜负关键
3. **烟雾机制**：karrigan 的烟雾可以让友方停留后不消耗移动次数，合理利用烟雾封锁关键区域
4. **Zephyr 控血**：主动技能自伤换取攀升减伤层数，配合被动在低血量时打出爆炸伤害
5. **あんパパン 资源加速**：技能瞬间补满手牌和能量，配合被动每 2 张卡额外摸牌回能
6. **地形利用**：不同地形消耗不同移动力，合理规划路线
7. **编队搭配**：建议搭配坦克 + 输出 + 辅助的组合，不要全选同一类型
8. **背景设置**：在设置界面可以选择喜欢的动态背景，进入战斗时会自动隐藏

## 🌐 联机系统

### 支持模式

| 场景 | 方式 | 说明 |
|------|------|------|
| **同一局域网** | 直接连 | 房间码自动显示本地 IP |
| **VPN 虚拟网络** | Radmin / ZeroTier | 自动检测 VPN 虚拟 IP（26.x/27.x/28.x/10.x）并优先使用 |
| **公网直连** | UPnP + 端口转发 | 自动 UPnP 映射端口，失败则需手动转发 |
| **本机双开** | 127.0.0.1 | 房间码复制粘贴或本地连接 |

### 连接流程

```
主机点「创建」
  ├─ 自动检测 VPN 虚拟 IP（Radmin 26.x / ZeroTier 28.x / 10.x）
  ├─ UPnP 自动端口映射（路由器支持则无需手动设置）
  ├─ HTTP 获取公网 IP（多个服务轮询 + 5s 超时）
  └─ 显示房间码（VPN IP > 公网 IP > 局域网 IP）

客户端点「加入」
  └─ 输入房间码（IP:端口）→ 直连
```

### 故障排除

如果连不上：
1. **双方装 Radmin VPN 或 ZeroTier** — 免费，一键组网，像局域网一样玩
2. **主机路由器设置端口转发** — 转发 UDP 端口到主机内网 IP
3. **检查防火墙** — 允许游戏进程通过防火墙
