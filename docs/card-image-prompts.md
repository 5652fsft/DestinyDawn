## 文件命名规则

图片保存为 `Assets/Sprites/Cards/<card_id>.png`，例如：
- `card_fireball.png`
- `card_heal.png`
- `card_strength.png`

完整 card_id 列表：
```
card_overload, card_ice_shard, card_siphon, card_poison_blade,
card_reckoning, card_small_heal, card_life_split, card_regen,
card_shield_overload, card_strength, card_fortify, card_haste,
card_double_edge, card_weakness, card_slow, card_mark, card_hemorrhage,
card_draw, card_cleanse, card_taunt, card_fireball, card_aim,
card_frostbite, card_shadowstep, card_heal, card_heal_wave, card_shield,
card_ice_shield, card_iron_wall, card_disarm, card_echo, card_firestorm,
card_arrow_rain, card_chain_lightning, card_mass_heal
```

> 提示：使用生图工具时，先代入风格统一前缀，再拼接具体卡牌描述。建议分辨率 512×768 或 768×1024。
