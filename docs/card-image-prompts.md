## 使用说明

1. 生图模型：直接用中文提示词即可
2. 批量生成：每行一个 `<文件名> — <画面描述>`，可逐行丢给模型
3. 分辨率：建议 512×768 或 768×1024（2:3 竖版）
4. 所有图片统一风格，每张居中展示一个清晰的魔法/技能效果
5. 保存到 `Assets/Sprites/Cards/<card_id>.png`
